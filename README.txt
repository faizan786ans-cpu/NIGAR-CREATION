NIGAR CREATION — starter ecommerce website

FILES
- index.html: page structure
- style.css: responsive styling
- script.js: sample products, search, category filters, sorting, cart and demo checkout

HOW TO PREVIEW
1. Extract the ZIP file.
2. Open index.html in a modern browser.
3. Internet is needed for Google Fonts; the site otherwise runs as a static demo.

IMPORTANT
- Product names, prices and visual swatches are sample content. Replace with your actual products and real product photos.
- Cart and checkout currently work only in the browser as a demo. Orders are not saved and payments are NOT processed.
- Before accepting real orders, connect a secure backend/database, order notifications, shipping workflow, privacy/terms/return policies, and a payment provider (for example Razorpay) or a properly configured COD process.
- Do not collect real customer information using this demo form.
- To publish, deploy these files to a static host for a preview; a production store needs backend functionality for real checkout.
